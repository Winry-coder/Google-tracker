## 🔍 QUICK REFERENCE

### **Key URLs**
```
Development:  http://localhost:3000
Production:   https://yourdomain.com (after deployment)
Login:        /login
Dashboard:    /dashboard
Campaigns:    /campaigns
Analytics:    /analytics
API Base:     /api/
```

### **Key Commands**
```bash
# Development
pnpm dev                    # Start dev server
pnpm build                  # Production build
pnpm lint                   # ESLint check

# Database
pnpm prisma generate       # Generate Prisma client
pnpm prisma db push        # Run migrations
pnpm prisma db seed        # Seed data

# Testing
pnpm test                           # Unit tests
pnpm exec playwright test           # E2E tests
pnpm exec playwright test --ui      # Interactive UI
```

### **Key Endpoints**
```
GET  /api/users           # List users
GET  /api/campaigns       # List campaigns
POST /api/sync            # Manual sync
GET  /api/sync/status     # Sync status
GET  /api/analytics/*     # Analytics data
```

### **Key Environment Variables**
```
NEXTAUTH_SECRET          # Session encryption
GOOGLE_CLIENT_ID         # OAuth credentials
GOOGLE_CLIENT_SECRET     # OAuth credentials
TURSO_DATABASE_URL       # Database connection
TOKEN_ENCRYPTION_KEY     # Token encryption
CRON_SECRET              # Cron authentication
```
